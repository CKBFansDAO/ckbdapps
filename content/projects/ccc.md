CCC (CKBers' Codebase) is the JavaScript and TypeScript toolkit for building on CKB, maintained by CKB DevRel. It covers building and signing transactions, querying the chain, and connecting wallets: one connector supports JoyID, MetaMask, OKX, UniSat, UTXO Global, Xverse and more, so a dApp can accept users from both the Bitcoin and Ethereum worlds.

Packages cover tokens (UDT), Spore digital objects, DID and multisig. The documentation includes a live playground for trying code in the browser, and CCC App is a ready-made web app for common wallet actions.
