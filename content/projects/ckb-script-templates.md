CKB Script Templates is the standard starting point for writing CKB on-chain scripts. Running `cargo generate` against the repository creates a workspace, and further templates add contracts and tests to it. The templates use the latest stable Rust and a stock clang, so the same native development flow works on Linux, macOS and Windows.

The repository is maintained by the Nervos Network team.
