CKB AI is a single Model Context Protocol (MCP) server that helps AI assistants such as Claude Code and Codex build contracts and applications on CKB. It gives them RPC tools for blocks, transactions, cells and network state; higher-level tools for common tasks such as checking an address or validating a transaction; developer utilities for deploying cells, managing accounts and requesting testnet funds; CKB documentation formatted for AI; and guided workflows for writing scripts, deploying and transferring.

The CKBDEV team hosts a public server you can add to your assistant with one command, or you can run it yourself from the open-source repository. The site also recommends tool stacks and CLAUDE.md / AGENTS.md guidelines for CKB projects. The server is in alpha, and the site is clear that it still needs a developer who understands CKB to guide it.
