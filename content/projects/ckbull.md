CKBull is a mobile wallet application developed by Peersyst Technology for the Nervos Network (CKB), launched in July 2022. Designed as a non-custodial wallet, it provides a user-friendly interface for managing CKB tokens, tokens bridged via ForceBridge, NFTs, and Nervos DAO deposits. Built on CKB's secure Layer 1 and UTXO-based Cell model, CKBull enables users to create multiple wallets, stake CKB in Nervos DAO to earn rewards, and manage diverse digital assets. The wallet supports both Android and iOS platforms, offering a customizable interface and comprehensive asset management capabilities.
